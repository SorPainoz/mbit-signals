# Options to interact remotely with a microbit

Interacting with a BBC micro:bit remotely depends on whether you are communicating wirelessly from another device nearby, controlling it over long distances (via the Internet), or using another micro:bit as a dedicated controller.

---

## 1. Local Wireless Interacting

### A. micro:bit-to-micro:bit Radio (2.4 GHz)

The micro:bit includes a built-in proprietary 2.4 GHz radio protocol.

* **How it works:** Program two (or more) micro:bits on the same `radio set group`. One unit acts as a remote transmitter (e.g., detecting button presses or tilt gestures via the accelerometer) and sends string or numeric payloads to the target micro:bit.
* **Best for:** Low latency, offline physical controllers (e.g., custom gamepads, remote RC cars).

### B. Bluetooth Low Energy (BLE)

The onboard BLE hardware enables direct communication with mobile devices, tablets, and PCs without extra hardware.

* **Official Mobile Apps:** Use the micro:bit Android or iOS apps to flash code, read sensor data, or control pins via Bluetooth.
* **Bluetooth HID (Human Interface Device):** Configures the micro:bit (V2 natively) as a Bluetooth keyboard, gamepad, or media remote.
* **Custom Mobile Apps:** Build custom smartphone controllers using platforms like **MIT App Inventor**, **Blynk**, or **Flutter** using the micro:bit BLE services (UART, LED service, Accelerometer service, Magnetometer service).

### C. WebBluetooth (Browser Direct)

* **How it works:** Chrome and Edge support WebBluetooth APIs. Browsers can read sensor states or send commands to a paired micro:bit directly from a web page without installing desktop software.
* **Best for:** Interactive web dashboards, browser-based games, and lightweight remote interfaces.

---

## 2. Serial & PC Gateways (Tethered Remote Control)

When a micro:bit is connected via USB to a host machine (PC, Raspberry Pi, or Mac), that host acts as a gateway to relay commands over longer distances.

### A. Serial / WebUSB Link

* **Python (`pyserial` / `bitio`):** Host scripts listen to the micro:bit’s USB serial output (`sys.stdout`) or write commands back to it.
* **WebUSB:** Direct serial communication through web browsers using MakeCode or custom JS web apps.

### B. Radio-to-Serial Bridge

* **How it works:** Leave target micro:bit #1 free (e.g., inside a robot or standalone sensor). Connect target micro:bit #2 to a PC via USB to act as a receiver. Send serial commands from your PC script/GUI to micro:bit #2, which relays them via Radio to micro:bit #1.

---

## 3. Web & Internet (IoT / Long Range)

Since the micro:bit does not have built-in Wi-Fi, internet connectivity relies on a host bridge:

### A. MQTT / HTTP via PC or Raspberry Pi

* Flash a MicroPython script onto the micro:bit that sends formatted text over the USB serial port.
* Run a Python daemon on a connected Raspberry Pi / PC to translate serial messages to **MQTT** topics (or HTTP REST endpoints) on services like **Adafruit IO**, **Thingspeak**, or **HiveMQ**.

### B. WebSockets via WebBluetooth

* Pair the micro:bit to a smartphone or computer via WebBluetooth, and let the web browser host a WebSocket client to send/receive real-time commands anywhere over the internet.

### C. Wi-Fi / Cellular Expansion Shields

* Attach external hardware add-ons (such as ESP8266 or ESP32 shields connected over UART/I2C) to give the micro:bit standalone Wi-Fi capabilities.

---

## 4. Infrared (IR) Control

* Add an infrared receiver module to one of the micro:bit’s GPIO pins.
* Use standard IR TV remotes or cheap mini keypads (NEC protocol) to transmit directional commands directly to the board.

## Summary Recommendation Matrix

| Interacting Goal | Recommended Method | Requirements |
| --- | --- | --- |
| **Simple micro:bit gamepad** | micro:bit Radio | 2× micro:bits |
| **Phone / Tablet Control** | Bluetooth Low Energy (BLE) or WebBluetooth | Mobile app or Web browser |
| **PC Mouse/Keyboard Emulation** | Bluetooth HID (V2) or Serial Script | Built-in BLE or Python `pyserial` |
| **Internet / Cloud Dashboard** | USB Serial / BLE to Pi/PC Gateway | PC/Pi running MQTT / Python script |
| **Physical TV Remote** | IR Receiver Expansion Module | IR remote + IR receiver shield/breakout |
